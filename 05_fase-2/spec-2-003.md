# SPEC-2-003 — Vínculo documento workspace ↔ arquivo SharePoint

**Fase:** 2 · **Status:** planejada · **Dono:** Ethos / implementador

## Resultado observável

Documento do workspace nasce SEM origem (badge ORIGEM PENDENTE, como hoje) e passa a poder ser completado escolhendo um arquivo do SharePoint pelo navegador: origem_url é preenchida com o link do arquivo, badge some, evento auditado com a origem. O fallback manual (colar URL) continua funcionando.

## Limites e dependências

- **Inclui:** endpoint server-side para resolver arquivo → link permanente; integração na edição do workspace item; auditoria; fallback manual preservado.
- **Fora:** upload (SPEC-2-004), sincronização bidirecional, alteração do arquivo no SharePoint.
- **Pré-condições:** T2.1 e T2.2 concluídas.

## Fluxo e regras

1. No cartão do projeto, aba Docs/Links: documento pendente ganha ação "Vincular do SharePoint".
2. Usuário escolhe o arquivo no navegador (SPEC-2-002); hook resolve o link permanente (Graph `@microsoft.graph.downloadUrl` ou webUrl).
3. Edição audita workspace_completado com origem SharePoint (caminho + link).
4. Documento sem origem continua nascendo pendente (CA-1-030 preservado).

| Cenário | Dado/condição | Resultado esperado | Caminho de erro |
|---|---|---|---|
| Principal | vínculo de arquivo existente | origem_url preenchida, badge some, auditado | — |
| Falha | arquivo movido/apagado no SharePoint | erro visível, item permanece pendente | nada parcial |
| Limite | vínculo manual por URL colada | segue funcionando (fallback) | — |
