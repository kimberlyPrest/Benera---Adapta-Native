# SPEC-2-002 — Navegador de arquivos do SharePoint

**Fase:** 2 · **Status:** planejada · **Dono:** Ethos / implementador

## Resultado observável

Usuário autorizado navega pastas e arquivos da biblioteca BENERACORP (raiz CONSULTORIA) pela UI do 63138: lista com nome, caminho, tamanho e data; busca por nome; tudo server-side via hook — o token Graph nunca chega ao front.

## Limites e dependências

- **Inclui:** hook server-side de listagem/busca (Graph), tela de navegação, escopo herdado da carteira (admin/líder tudo; consultor/revisor com vínculo), auditoria de acesso.
- **Fora:** preview de conteúdo, edição no SharePoint, vínculo com workspace (SPEC-2-003).
- **Pré-condições:** T2.1 concluída.

## Fluxo e regras

1. Hook `/backend/v1/sharepoint/listar?caminho=...&busca=...` — server-side com token do backend.
2. Escopo: sem vínculo → 403 auditado (padrão Fase 1).
3. Auditoria: sharepoint_consulta com ator, caminho e nº de itens.
4. Erro de caminho → 404 limpo; erro do Graph → mensagem visível, sem stack.

| Cenário | Dado/condição | Resultado esperado | Caminho de erro |
|---|---|---|---|
| Principal | pasta CONSULTORIA | lista com pastas 00–90 e arquivos | — |
| Falha | usuário sem vínculo | 403 auditado | access_denied |
| Limite | pasta vazia | 200 com 0 itens | — |
